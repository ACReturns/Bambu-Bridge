# Bambulab Widget
I always wanted the Bambu Handy app to be pin-able and display the active printer from the phone home screen but the app didn't have the feature. Having to open the app & go to the printer section to see where I was with the current print always seemed silly so I started building this to see what was possible and how useful it would actually be. A pin-able app that lets you track multiple 3d printers from your phones home screen so you never need to open an app when all the necessary information is right there for you to see. In it's current state it only works on Android and requires LAN mode to connect. The future plans are to make it connect online and work on iOS as well. The UI is basic at the moment and just to get the point across that it works and to determine what data is actually needed to be displayed first.
